一、github常用ssh连接进行远程连接，ssh设置对于每台电脑和一个github账号，需要配对一对公私钥，
##具体的命令步骤是在本机电脑执行：
（1）ssh-keygen -t ed25519 -C "对应的邮箱账号"
（2）一路回车
（3）通过 Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub" | Set-Clipboard 命令复制公钥
（4）在github的setting  ->   SSH and GPG keys  ->  New SSH key->  复制公钥并保存
（5）在本机测试 命令 ：ssh -T -p 443 git@ssh.github.com   如果成功，则返回：Hi username! You've successfully authenticated, but GitHub does not provide shell access.

以上是配置ssh一套公钥私钥的方法

二、接下来是进行git配置，git的下载我之前已经完成，这里直接配置初始化仓库
（1）在github新建一个仓库
（2）在项目对应文件夹中依次执行下列命令：
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin ssh://git@ssh.github.com:443/邮箱名/项目名.git
git push -u origin main

配置完成

三、还出现了一个小问题，因为我之前注册过一个github账号，而这次的仓库是在一个新的github账号下保存的，这次的提交显示提交人依然是我之前的github账号，所以需要修改提交人。
修改步骤如下：
git config user.name "用户名"
git config user.email "当前账号已验证的邮箱"

四、每次提交时的执行步骤是：
git add .
git commit -m "提交信息"
git push
